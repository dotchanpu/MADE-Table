09 — DIRECTIVES

Consistent interface rules

Separate data, interaction, and visual hierarchy to keep growing pages readable.

Do

  • Keep a clear reading order.Runs, pipeline, events, and artifacts.
  • Preserve source data.Phases, variables, statuses, and API contracts.
  • Make room for long content.Wrap, expose full titles, and allow table scrolling.
  • Name every status.Color is supplementary.
  • Use consistent controls.Keep interactions consistent across detail pages.
  • Keep selection stable.Do not rebuild unchanged run lists during polling.

Don't

  • Do not confuse service state.Historical completion does not mean currently online.
  • Avoid decorative color bands.Keep static metrics neutral.
  • Keep helper text quiet.Supporting labels stay below primary headings.
  • Do not over-compress tables.Allow horizontal scrolling on narrow screens.
  • Avoid continuously scaling cards.Keep motion local and restrained.
  • Do not shrink text to fit.Scroll when content exceeds the available space.
